# Klar Finanzplaner

Vollständiger portabler Stand mit lokaler Bilderkennung und optionaler Supabase-Anmeldung. Keine Nutzerdaten oder privaten Schlüssel enthalten.

Netlify: Branch `klar-finanzplaner` auswählen. Die netlify.toml im Repository legt Basis und Veröffentlichungsordner fest; kein Next.js-Build erforderlich.

Cloud-Anmeldung und Speichern müssen nach dem Deployment mit einem echten Benutzer geprüft werden. Claude-Anbindung und iPhone-Push sind noch nicht implementiert.
